## 元玺 v1.8.1 更新日志

![元玺 v1.8.1 封面图](images/1.8.1_cover.png)

不是每一件事都需要同样的执行力度。本次更新可以在对话里按任务难度选用 **元玺 Lite、Pro 或 Max**；同时接入 **任务 Web Push 通知**，长时间任务完成后，浏览器会提醒你。

### 本次两项核心升级

1. **Agent 档位选择**：Lite、Pro、Max 三档，按任务轻重切换。
2. **任务 Web Push 通知**：任务完成时，即使当前标签不在前台，浏览器也会弹出提醒。

---

## 核心升级一：Agent 档位选择

### 按任务难度选档，不必一律拉满

![Agent 档位选择配图](images/1.8.1_content_1.png)

整理纪要、改一封邮件，和做一份高难度方案、跑复杂推演，所需的能力并不一样。现在可以在对话中选择 Agent 档位：

- **元玺 Lite**：适合日常任务的轻量档
- **元玺 Pro**：适合大多数复杂任务
- **元玺 Max**：面向高难复杂任务的高性能档

三档都能把任务做完，差别在深度、耗时和积分。日常工作用 Lite 即可，真正难的任务再切到 Pro 或 Max。

#### 选档也会改变消耗

![同一任务三档积分对照](images/1.8.1_content_5.png)

档位越高，同一件事通常越费积分。用同一条「整理会议纪要」做过一次对照，方便感受量级：Lite 大约 0.2 积分，Pro 大约是 2 倍，Max 大约是 8 倍。

这只是一次轻量任务的参考，不是固定单价。内容、工具调用、对话轮次不同，消耗都会变，实际以当次任务为准。

#### 这些时候可以这样选档

- **Lite**：纪要整理、格式调整、短文改写、日常问答。
- **Pro**：大多数方案撰写、PPT 制作、常规分析与研究。
- **Max**：高难度推演、多约束规划、长链路复杂任务。

## 核心升级二：任务 Web Push 通知

### 任务还在跑，人可以先去忙别的

![任务 Web Push 通知配图](images/1.8.1_content_3.png)

做一份 PPT、写一篇长报告、跑一轮决策推演，往往需要一段时间。过去只能把页面开着，或过一会儿再回来看有没有做完。

现在可以开启任务的 Web Push 通知。任务完成后，浏览器会弹出提醒。即使已经切去处理别的事情，也不容易错过结果。点开通知即可回到对应会话。

#### 真实场景：报告还在生成，先去开了个会

![任务 Web Push 通知场景案例](images/1.8.1_content_4.png)

你让元玺撰写一份行业研究报告。任务已经开始，但还要一会儿才能完成。过去只能把对话页留在桌面，或过一会儿再回来刷新。

现在开启通知后，可以先去开会。报告完成后，浏览器会提醒你，点开就能查看结果或继续补充要求。

#### 这些时候也适合打开通知

- **生成 PPT**：多页演示文稿需要较长时间，做完再回来查看。
- **撰写长文档**：报告、方案正在生成时，不必一直守在对话页。
- **决策推演**：推演还在进行，先去核对数据或开会。
- **浏览器任务**：连接器正在操作网页流程，完成后需要你接手。
